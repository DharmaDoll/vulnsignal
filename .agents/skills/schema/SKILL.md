# SQLite スキーマの変更

[スキーマ](../../../docs/SCHEMA.md)、`db/migrate.py` と直近の `sql/migrations/` を確認する。適用済みの移行は保持し、新しい番号の移行と `sql/schema.sql` を合わせる。テスト・スクリプトの DB 操作前にマイグレーションを実行する。

`signals` は追記専用。マートの派生行から元の `signal_id` をたどれるようにする。索引とカーソルを同じトランザクションで確定させ、既存 DB のバックフィルと繰り返し更新の両方を検証する。
